# Viewer Parrots 1.2.0 🦜

Fabric-мод для одиночной игры в Minecraft **1.21.1**: зрители Twitch создают
своих попугаев и управляют ими командами в чате. У птиц есть шляпы, реальные
крики, нейронные голоса и возможность сидеть на плечах стримера.

**[Скачать готовый мод](https://github.com/BigZet/minecraft-parrot/releases/latest)** ·
**[Установка с нуля](docs/quickstart-ru.md)** ·
**[Настройка Twitch и речи](docs/twitch-setup-ru.md)**

Мод нужен только стримеру. Зрители пользуются обычным Twitch-чатом.
Публичный чат читается без Twitch-токена, регистрации приложения и 2FA.
Интернет нужен для Twitch и, при включённой речи, OpenRouter.

## Панель управления в игре

**F8** (клавиша переназначается), кнопка **Viewer Parrots** в главном меню и Esc.
Девять разделов: Twitch и вход через браузер, команды и роли, лимиты и модерация,
птицы, поведение, голоса и платная озвучка, рулетка, профили и дополнительные настройки.
Панель работает в одиночном мире без читов; игровые действия доступны при открытом мире.

Настройки сохраняются в `config/viewerparrots-settings.json`; старые конфиги импортируются
один раз. Время рулетки и другие интервалы редактируются в секундах.
[Установка и подключение с нуля](docs/quickstart-ru.md).

## Установка одним файлом

Для стримера без опыта с модами: скачайте `viewerparrots-1.2.0-installer.zip`
из [GitHub Releases](https://github.com/BigZet/minecraft-parrot/releases/latest),
распакуйте и запустите **«Установить Viewer Parrots.cmd»**. Установщик ставит
portable Prism Launcher в `%LOCALAPPDATA%\ViewerParrots`, создаёт инстанс
Minecraft 1.21.1 + Fabric, кладёт Fabric API и мод, записывает Twitch-канал
и создаёт ярлык на рабочем столе; Java 21 и Minecraft Prism скачивает сам.
Остаётся войти в Microsoft-аккаунт. Пошагово — в [installer/ИНСТРУКЦИЯ.txt](installer/ИНСТРУКЦИЯ.txt);
исходник — [installer/install.ps1](installer/install.ps1), сборка архива —
`scripts/package-installer.ps1`.

## Установка вручную

| Компонент | Версия |
|---|---|
| Minecraft Java Edition | 1.21.1 |
| Java | 21 |
| Fabric Loader | 0.19.5 |
| Fabric API | 0.116.17+1.21.1 |
| Viewer Parrots | 1.2.0 |

1. Установите [Prism Launcher](https://prismlauncher.org/download/), добавьте
   Minecraft-инстанс **1.21.1** и установите в него **Fabric Loader 0.19.5**.
   Для запуска выберите Java 21.
2. Скачайте `viewerparrots-1.2.0.jar` из
   [GitHub Releases](https://github.com/BigZet/minecraft-parrot/releases/latest).
   Положите его и [Fabric API](https://modrinth.com/mod/fabric-api)
   **0.116.17+1.21.1** в папку `mods` этого инстанса.
3. Запустите одиночный мир с разрешёнными командами и введите
   `/vp setstreamer <ваш_Minecraft_ник>`.
4. В папке `config` того же инстанса откройте `viewerparrots-twitch.json`:

```json
{
  "autoConnect": true,
  "channel": "your_login",
  "login": ""
}
```

Вместо `your_login` укажите логин своего Twitch-канала, без ссылки.
Файл `viewerparrots-twitch-token.txt` для этого способа не нужен:
если он уже есть, оставьте его пустым. В игре выполните `/vp twitch connect`,
затем `/vp twitch status` и дождитесь `CONNECTED`.
Изменение Twitch-настроек применяется при подключении, перезапуск игры не нужен.

Зритель пишет `!parrot` и получает свою птицу с именем из Twitch.
Оставьте мир открытым и снимите паузу, чтобы команды выполнялись.

В Releases также доступен ZIP-пакет с JAR в `mods/` и инструкцией
`QUICKSTART-RU.md`. Из него скопируйте JAR в инстанс; Fabric API установите отдельно.

## Команды Twitch-чата

Доступны 19 команд, включая создание птицы.

| Команда | Действие попугая отправителя |
|---|---|
| `!parrot` | Создать птицу; повтор не создаёт второго попугая |
| `!come` | Прилететь к стримеру; при расстоянии больше 64 блоков — телепортироваться рядом |
| `!follow` | Следовать за стримером |
| `!free` | Свободно гулять и перелетать с места на место, делая паузы |
| `!freefollow` | Вести себя свободно рядом со стримером и догонять его |
| `!view` | Смотреть на стримера, сохраняя текущее движение или сидение |
| `!deview` | Выключить наблюдение за стримером |
| `!arm` | Сесть на плечо стримера |
| `!dearm` | Слететь с плеча и перейти в `freefollow` |
| `!sit` | Остаться на месте |
| `!dance` | Танцевать 10 секунд |
| `!spin` | Крутиться 3 секунды со скоростью 10 оборотов в секунду |
| `!scream` | Воспроизвести случайный настоящий крик из пяти записей |
| `!say Текст` | Произнести первые 30 слов текста закреплённым голосом |
| `!say [стиль] Текст` | То же с интонацией: `шёпот`, `зло`, `грусть`, `радость`, `страх`, `усталость`, `крик`, `сарказм` |
| `!love` | Показать ванильные сердечки над птицей |
| `!hat` | Надеть случайную шляпу из восьми; повтор выбирает другую |
| `!dehat` | Снять шляпу |
| `!color` | Сменить окрас на случайный другой из пяти; `!color синий` — выбрать: `красный`, `синий`, `зелёный`, `жёлтый`, `серый` |
| `!name Кеша` | Дать птице кличку (1–32 символа, без `§`); `!name` без текста возвращает имя зрителя |
| `!emote` | Случайная эмоция на 2 секунды; `!emote поклон` — выбрать: `поклон`, `нет`, `кивок`, `прыжок`. Не на плече и не во время `!spin`/`!dance` |
| `!fight @ник` | Вызвать птицу другого зрителя на дуэль; у цели 60 секунд на `!accept` или `!decline` |
| `!accept` / `!decline` | Принять или отклонить вызов; ответный `!fight` тоже считается согласием |
| `!exp` | Уронить над птицей один пузырёк опыта: он разбивается и даёт опыт |
| `!roulette` | Прокрутить ленту предметов над птицей; приз падает сверху на месте попугая |

Кроме `!say`, `!color`, `!name`, `!emote` и `!fight`, команды пишутся без аргументов. Зритель управляет только своей
птицей; её владелец определяется по постоянному Twitch ID.

Новый попугай начинает в `free`. В этом режиме он использует обычные полёты
и посадки попугая, а не летает непрерывно. В `freefollow` птица гуляет
в радиусе примерно 12 блоков; если стример ушёл дальше, догоняет до 8 блоков
и снова гуляет. Дальний перенос использует те же настройки, что `come`.

В `view` сначала поворачивается голова: до 75° в стороны и 40° вверх/вниз.
Когда поворота головы недостаточно, тело плавно доворачивается,
не быстрее 10° за игровой тик.

На плечах помещаются две птицы. Третий `!arm` освобождает одно плечо:
вытесненный попугай переходит в `freefollow`, новый занимает его место.
При заполненных плечах вытеснение чередуется между левым и правым.
После обычного ванильного сброса с плеча птица также переходит в `freefollow`.
Сидящих на плечах попугаев удобно смотреть через **F5**.

Задержки считаются отдельно для каждого зрителя:

- `!view`/`!deview`, `!arm`/`!dearm` и `!hat`/`!dehat` — по 2 секунды,
  внутри каждой пары задержка общая;
- `!free`, `!freefollow` и `!say` — по 2 секунды;
- `!emote` — 3 секунды; `!spin` и `!color` — 5 секунд; `!exp` — 30 секунд;
  `!name`, `!fight` и `!roulette` — 60 секунд; `!accept`/`!decline` без задержки.

## Дуэли

Дуэль состоится только по согласию: `!fight @ник` — вызов, цель отвечает
`!accept` или `!decline` в течение 60 секунд. Вызов виден на стриме: птица
вызывающего кричит, над обеими птицами висят сердитые частицы, а стример
видит в чате строку `[Дуэль] numnerd вызывает gosha на дуэль: !accept или
!decline`. У птицы может быть один входящий и один исходящий вызов; занятая
птица новые вызовы не принимает. Соперник ищется по имени зрителя или кличке
без учёта регистра, можно указать `twitch:id`.

После `!accept` обе птицы должны быть в мире, не на плече и ближе 48 блоков
друг от друга (иначе — `!come` и повторить). Три секунды потасовки с перьями,
затем случайный исход: победитель танцует, проигравший сидит с дымком, и обе
птицы возвращаются к своему поведению. Урона нет. Любая своя команда участника
(`!come`, `!sit`…) прерывает дуэль без победителя. Стример может снять все
вызовы и дуэли кнопкой в **F8 → Поведение**.

Кличка показывается над птицей вместо имени зрителя: в формате имени
(`nameFormat`, по умолчанию `{viewer_name}`) этот плейсхолдер подставляет кличку,
если она задана, а `{twitch_name}` — всегда имя зрителя. В списках, рулетке
и панели зритель по-прежнему называется своим именем. Запрещённые подстроки
для кличек — `forbiddenNameWords` в разделе модерации настроек.

## Рулетка предметов

`!roulette` запускает ленту иконок Minecraft-предметов над своей птицей:
4 секунды прокрутки и 2 секунды показа результата. Лента движется вместе с
птицей, включая попугая на плече; в этом случае переключитесь на **F5**.
Рулетка показывает пять иконок, рамку, стрелку и эффекты, без текстовых подписей.
Птица продолжает своё движение или сидение, а каждый завершённый розыгрыш
даёт приз: предмет появляется сверху на текущем месте попугая и падает
вертикально, как пузырёк `!exp`. При заполненном инвентаре предмет остаётся
лежать в мире, и его можно подобрать позже.

Одновременно крутится одна рулетка на весь мир. Остальные заявки идут
по порядку в очередь до 16 розыгрышей. Задержка между заявками одного зрителя —
60 секунд. Для команды нужна уже существующая птица, загруженная в мире
или сидящая на плече. В игре доступна `/vp roulette <viewerId>`.

Настройки создаются в **`config/viewerparrots-roulette.json`**. По умолчанию
веса категорий `common` / `useful` / `rare` / `jackpot` равны **65 / 25 / 9 / 1**.
В файле можно менять веса, списки предметов и количество каждого приза;
после сохранения выполните `/vp reload`.

## Речь попугаев — необязательно

`!say` использует **OpenRouter** и модель **`elevenlabs/eleven-v4-turbo`**.
Нужен личный API-ключ OpenRouter с доступными платными кредитами.
Остальные команды работают без него.

Сохраните ключ одной строкой в
`config/viewerparrots-openrouter-token.txt` Minecraft-инстанса
и заново откройте мир. Альтернатива — переменная окружения
`OPENROUTER_API_KEY` в процессе Minecraft.
Ключ не вводится в игровой или Twitch-чат.

Встроены 24 уникальных голоса. Первые 24 птицы получают случайные голоса без
повторов; далее голос выбирается случайно среди наименее используемых.
Голос сохраняется в мире.
Текст длиннее 30 слов обрезается; птица воспроизводит речь в своей позиции.

Интонация задаётся первым токеном в квадратных скобках: `!say [шёпот] я тут`.
Это audio-теги ElevenLabs (`[whispers]`, `[angry]`…), которые модель читает прямо
из текста — без второго запроса. Без стиля интонацию задаёт характер птицы:
`COWARD` говорит нервно, `LAZY` устало, `LOUD` громко и возбуждённо, `NORMAL` обычно.
Теги стилей и характеров редактируются в **F8 → Озвучка**; неизвестный стиль
не озвучивается, а скобки внутри самого текста вырезаются.
[Подробная настройка речи и VPN](docs/twitch-setup-ru.md#речь-попугаев).

## Настройки и сохранение

Основные настройки: `config/viewerparrots.json`.
После изменения выполните `/vp reload`; некоторые настройки очереди
и хранения требуют повторного открытия мира.
По умолчанию доступно до 50 попугаев, они защищены от обычного урона.

Птицы и их намерения сохраняются отдельно для каждого мира,
в `<world>/data/viewerparrots/`. Голоса сохраняются в мире,
шляпы и режим взгляда — вместе с птицей.
После повторного открытия мира сидение на плечах восстанавливается;
незаконченные `come`, `dance` и вращение заново не запускаются.
Перед обновлением закройте мир и сделайте копию его папки.

Игровая справка — `/vp help`, сведения о птице — `/vp info <viewerId>`.
Ручная проверка без Twitch: `/vp create viewer1 Тест`, затем
`/vp freefollow viewer1`, `/vp view viewer1` или `/vp arm viewer1`.
Удаление тестовой птицы: `/vp remove viewer1`.

## Сборка из исходников

Готовый JAR из Releases не требует Gradle или самостоятельной сборки.
Для разработки нужен JDK 21:

```powershell
# Windows
.\scripts\verify.ps1
```

```sh
# Linux / macOS
./gradlew assemble --console=plain
```

Результат: `build/libs/viewerparrots-1.2.0.jar`.
Обычная проверка проекта — одна сборка и короткий прогон изменённого сценария.
Дополнительные тесты доступны через `scripts/verify.ps1 -Extended`.
