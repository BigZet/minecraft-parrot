# Шляпы попугаев — 3D-предпросмотр

Восемь отдельных моделей. В моде `!hat` надевает случайную шляпу, повторный
`!hat` меняет её на другую, `!dehat` снимает:

- Корона — `royal_crown`.
- Цилиндр — `top_hat`.
- Пиратская шляпа — `pirate_hat`.
- Грибная шляпа — `mushroom_hat`.
- Шляпа волшебника — `wizard_hat`.
- Кепка с пропеллером — `propeller_cap`.
- Ковбойская шляпа — `cowboy_hat`.
- Шляпа НЛО — `ufo_hat`.

Из корня репозитория запустите:

```text
python assets/hat-studio/serve.py
```

Откройте напечатанный локальный URL. Сервер слушает только `127.0.0.1`,
выбирает свободный порт и отдаёт файлы этой папки. Остановка — `Ctrl+C`.

Для редактирования откройте нужный файл `bbmodel/<имя>.bbmodel` в Blockbench.
GLB для других 3D-редакторов находится в `glb/*.glb`.
Дополнительный экспорт в формат Minecraft находится в `models/item/*.json`
и `textures/item/*.png`. Текущий мод строит шляпы из каталога кубоидов
`src/main/resources/assets/viewerparrots/hats/catalog.json`.

`viewer-parrot-hats.zip` содержит весь набор с локальным предпросмотром.
`hat-models.zip` — компактный архив моделей и генератора без страницы примерки.

Шляпы уже подключены к моду: масштаб и смещение подобраны относительно головы
попугая. Шляпа движется вместе с головой, в том числе на плече стримера;
ванильный хохолок скрывается, пока надета шляпа. Выбор сохраняется при закрытии
и повторном открытии мира. При изменении дизайна обновите каталог в ресурсах
мода и проверьте посадку шляпы в игре.
