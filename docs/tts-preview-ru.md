# Проверка голосов ElevenLabs через OpenRouter

Локальная страница позволяет вставить `voice_id`, выбрать модель и озвучить
русский текст. Каждая генерация оплачивается с баланса OpenRouter и запускается
только кнопкой «Озвучить». Готовый MP3 можно прослушать повторно или скачать.

Запуск из PowerShell 7 в папке проекта:

```powershell
.\scripts\tts-preview.ps1
```

Открой напечатанный адрес `http://127.0.0.1:.../`. На странице можно выбрать
готовый пример голоса или вставить любой свой ID. Наличие ID в подборке не
гарантирует доступность конкретного голоса в аккаунте провайдера: в таком случае
страница покажет ответ OpenRouter. Для приватных клонированных/созданных голосов
нужен ключ ElevenLabs, подключённый к OpenRouter через BYOK.

Ключ хранится вне проекта в `%LOCALAPPDATA%\ViewerParrots\openrouter-key.dpapi`,
зашифрован средствами Windows для текущего пользователя. Он не отдаётся браузеру
и не записывается в логи. Для замены ключа останови сервер и запусти:

```powershell
.\scripts\tts-preview.ps1 -SetKey
```

Для остановки сервера в консольном запуске нажми Ctrl+C. В текущем сеансе Codex
сервер может работать в фоне; его адрес и PID находятся в игнорируемом файле
`artifacts/tts-preview/server-info.json`.

Короткая проверка обработчика без платной генерации:

```powershell
python -m unittest discover -s scripts/tests -p test_tts_preview.py -v
```
