# Twitch и речь попугаев

Сначала установите готовый мод по [инструкции с нуля](quickstart-ru.md).
Пути `config/...` ниже относятся к папке Minecraft-инстанса стримера.
В Prism её можно открыть через контекстное меню инстанса.

## Публичный Twitch-чат без токена

После первого открытия мира мод создаёт `config/viewerparrots-twitch.json`.
Заполните его так:

```json
{
  "autoConnect": true,
  "channel": "your_login",
  "login": ""
}
```

`channel` — логин канала без `https://www.twitch.tv/`.
`login` оставьте пустым. `config/viewerparrots-twitch-token.txt`
не нужен; существующий файл оставьте пустым.
Мод прочитает публичный чат как гость, без Twitch-приложения и 2FA.
Зрители пишут команды со своих обычных Twitch-аккаунтов.

В одиночном мире с разрешёнными командами:

```text
/vp setstreamer <ваш_Minecraft_ник>
/vp twitch connect
/vp twitch status
```

Дождитесь `CONNECTED`. Стример назначается для текущего мира;
логин канала задаётся для Minecraft-инстанса.
Менять Twitch-файл можно при открытом мире: `connect` перечитывает его
и заново подключается. Полный перезапуск Minecraft не требуется.
`autoConnect: true` включает автоматическое подключение при открытии мира.

Основные состояния:

| Статус | Значение |
|---|---|
| `CONNECTING` | Выполняется подключение |
| `CONNECTED` | Чат подключён |
| `RECONNECTING` | Повторная попытка после обрыва сети |
| `AUTH_FAILED` | Twitch отказал во входе; проверьте или очистите токен |

`/vp twitch status` также показывает очередь и результат последней команды.
Для отключения: `/vp twitch disconnect`. Птицы сохраняются в мире.
При выходе из мира соединение закрывается, очередь очищается.
Мод не отправляет ответы бота в Twitch-чат.

## Команды зрителей

Зритель сначала отправляет **`!parrot`**, затем управляет своей птицей.
Встроены 18 команд — [таблица всех команд](../README.md#команды-twitch-чата).
Только `!say` принимает текст; остальные команды пишутся без аргументов.

Владелец определяется по Twitch ID отправителя. Смена ника не создаёт
новую птицу, повтор `!parrot` не создаёт дубль.
Зритель не указывает ID чужой птицы и не получает административные команды.
По умолчанию в мире разрешено до 50 попугаев.

Во время проверки снимите паузу в одиночной игре. При открытом меню Esc
сообщение может попасть в очередь, но действие ждёт игровых тиков.

## Речь попугаев

`!say Привет, стример!` произносит первые 30 слов текста голосом птицы отправителя.
Речь генерирует **OpenRouter**, модель **`elevenlabs/eleven-v4-turbo`**.
Нужны личный API-ключ и доступные платные кредиты OpenRouter.
Для остальных команд ключ речи не требуется.

Самый простой вариант на любом компьютере:

1. Создайте `config/viewerparrots-openrouter-token.txt` в Minecraft-инстансе.
2. Сохраните ключ в одной строке, без кавычек и дополнительных полей.
3. Закройте мир и откройте его снова.
4. Проверьте `!say Привет, стример!` в Twitch-чате.

Ключ не нужно вводить в чат, в JSON-конфиг мода или в данные мира.
В Windows при сохранении включите отображение расширений файлов,
чтобы не получить имя `viewerparrots-openrouter-token.txt.txt`.

Альтернативный способ: задайте **`OPENROUTER_API_KEY`** в окружении процесса
Minecraft. Эта переменная имеет приоритет над файлом ключа.
Если вы задали её после запуска лаунчера, перезапустите лаунчер и Minecraft,
чтобы новый процесс получил переменную.

На Windows также сохранена совместимость с локальным тестером голосов:
при отсутствии переменной и файла мод может прочитать его прежний
`%LOCALAPPDATA%/ViewerParrots/openrouter-key.dpapi` под тем же Windows-пользователем.
Это дополнительный вариант; для новой установки достаточно обычного файла ключа.

В мод встроены 12 голосов. Голос назначается птице случайно и сохраняется
в данных мира. Пока есть свободные голоса, повторов нет; после двенадцатой
птицы выбирается случайный голос среди наименее занятых.
Повторные `!say` и перезаход в мир используют прежний голос.
Записывать `voice_id` для начала работы не требуется.

Речь воспроизводится из позиции птицы. Задержка повторной команды — 2 секунды
на зрителя; одновременно у него может выполняться один запрос.
Общая очередь вмещает 16 ожидающих реплик и одну выполняющуюся.
Сетевой запрос выполняется в фоне и не блокирует игровой поток.

### OpenRouter и VPN

Мод обращается к:

```text
https://openrouter.ai/api/v1/audio/speech
```

Для этого нужен доступ к **`openrouter.ai` по TCP 443** из процесса Minecraft.
Если VPN работает только для выбранных приложений, добавьте Minecraft:
обычно это **`javaw.exe`** в Windows или процесс **Java** на другой системе.
Лаунчер и браузер могут иметь доступ к сети, пока запущенный ими Java-процесс
остаётся вне VPN.

Отдельный локальный тестер голосов, если вы им пользуетесь, работает через
**`python.exe`**. Успешная озвучка в браузере или тестере сама по себе
не подтверждает доступ Minecraft к OpenRouter.

## Если нужен вход Twitch по аккаунту

Этот раздел необязателен: для публичного чата выше достаточно гостевого входа.
Используйте его, если хотите подключаться под своим Twitch-аккаунтом.

1. Включите 2FA на своём Twitch-аккаунте и создайте собственное приложение
   в [Twitch Developer Console](https://dev.twitch.tv/console/apps).
2. Выберите тип клиента **Public** для Device Code Flow и скопируйте его Client ID.
3. На Windows с PowerShell 7 скачайте исходники проекта и запустите помощник,
   подставив **все три своих значения**:

```powershell
pwsh -NoProfile -File scripts/twitch-login.ps1 `
  -ClientId <Client_ID_вашего_приложения> `
  -Login <Twitch_логин_авторизуемого_аккаунта> `
  -TokenPath "<путь_к_Minecraft_инстансу>/config/viewerparrots-twitch-token.txt"
```

Помощник покажет ссылку и код. Откройте ссылку, авторизуйте свой аккаунт
и разрешите чтение чата (`chat:read`). Скрипт сохранит токен в заданный файл.
Указание `-Login` и `-TokenPath` обязательно для вашей установки:
не используйте локальные значения по умолчанию из чужого инстанса.

В `viewerparrots-twitch.json` впишите логин **авторизованного аккаунта**
в поле `login`, а имя читаемого канала — в `channel`.
Затем выполните `/vp twitch connect`.
На другой системе можно получить пользовательский токен
с разрешением `chat:read` своим OAuth-инструментом и сохранить его одной строкой
в тот же файл; префикс `oauth:` допускается.

Токен Device Code Flow обычно действует около четырёх часов.
Автообновления токена в этой версии нет: при истечении повторите получение
и выполните `/vp twitch connect`. Попугаи и мир при этом сохраняются.
Чтобы вернуться к гостевому входу, очистите файл токена и поле `login`.

## Короткая диагностика

| Ошибка или симптом | Решение |
|---|---|
| `AUTH_FAILED` в гостевом режиме | Очистите `viewerparrots-twitch-token.txt`, оставьте `login` пустым и повторите `connect` |
| `AUTH_FAILED` с токеном | Проверьте соответствие `login` авторизованному аккаунту и `chat:read`; обновите истёкший токен |
| `TARGET_NOT_CONFIGURED` | Выполните `/vp setstreamer <ваш_Minecraft_ник>` в текущем мире |
| `TARGET_UNAVAILABLE` | Целевой игрок должен быть жив и находиться в игре |
| `VIEWER_NOT_FOUND` | Отправьте `!parrot` с аккаунта зрителя |
| `PARROT_ALREADY_EXISTS` | Птица уже создана; управляйте ею следующей командой |
| `COMMAND_ON_COOLDOWN` | Подождите; для `!exp` — 30 секунд, `!spin` — 5 секунд |
| `GLOBAL_RATE_LIMITED` | Общий лимит действий занят; повторите позже |
| `CONNECTED`, но команда ждёт | Снимите паузу, проверьте имя канала и точное написание команды |
| `SPEECH_NOT_CONFIGURED` | Проверьте файл OpenRouter-ключа или переменную; после изменения заново откройте мир |
| `SPEECH_FAILED` | Проверьте ключ, кредиты OpenRouter и доступ Java к `openrouter.ai` |

Если `/vp` вообще недоступна, проверьте загрузку мода и разрешение команд в мире.
Настройки Twitch читаются при `connect`; ключ речи — при открытии мира.
