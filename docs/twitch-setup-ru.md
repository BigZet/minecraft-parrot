# Twitch и речь попугаев

Актуальная настройка выполняется в панели Minecraft: **F8 → Twitch**.
[Краткая инструкция с нуля](quickstart-ru.md) включает гостевое чтение, вход
через браузер с автоматическим продлением и настройку OpenRouter.

- Для публичного чата достаточно канала и гостевого режима.
- Для Device Code Flow нужен Client ID публичного приложения Twitch; Client Secret не нужен.
- Секреты сохраняются отдельно от профилей, на Windows — под защитой DPAPI.
- `!say` использует OpenRouter; ключ заменяется в скрытом поле раздела **Озвучка и голоса**.
- Платные пробы голосов и реплики входят в сохраняемый часовой расход.
- При паузе новые чат-команды пропускаются. Twitch и авторизация продолжают работать.

Единый источник настроек: `config/viewerparrots-settings.json`.
Старые JSON-конфиги читаются только при первом импорте. Совместимость со старым
access token сохраняется, но refresh token выдаётся только после нового входа.

[Все команды зрителей](../README.md#команды-twitch-чата).
Мод не отправляет сообщения бота в Twitch-чат.
