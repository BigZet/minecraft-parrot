# Viewer Parrots 1.2.0

Фановый мод для одиночной игры стримера: зрители Twitch-чата создают своих
попугаев и управляют ими. Пять новых команд зрителей, все проверены в игре.

## Что нового

- **`!say [стиль] текст`** — интонации: `шёпот`, `зло`, `грусть`, `радость`,
  `страх`, `усталость`, `крик`, `сарказм`. Это audio-теги ElevenLabs, второго
  запроса нет. Без стиля интонацию задаёт характер птицы (трусливая нервничает,
  ленивая устала, громкая кричит). Теги редактируются в F8 → Озвучка.
- **`!color`** — другой случайный окрас; `!color синий` — по имени. Сохраняется
  в записи птицы и переживает перезаход.
- **`!name Кеша`** — кличка над птицей; `!name` без текста возвращает имя зрителя.
  Стоп-слова для кличек — в F8 → Модерация.
- **`!emote`** — поклон, «нет», кивок, прыжок; `!emote поклон` — по имени.
- **`!fight @ник`** — дуэль по согласию: цель отвечает `!accept` или `!decline`
  в течение 60 секунд. Три секунды потасовки без урона, случайный исход:
  победитель танцует, проигравший сидит с дымком. Своя команда участника
  прерывает дуэль. Кнопка «Отменить все дуэли» в F8 → Поведение.
- Стримеру: `/vp color|name|emote <viewer> [текст]` и `/vp fight <viewer> <соперник>`.
- Twitch: причина реконнекта (класс исключения) теперь пишется в лог.
- Загрузчик ключа OpenRouter усилен (BOM в `viewerparrots-openrouter-token.txt`,
  DPAPI-резерв импортирует модуль Security явно). Надёжный способ задать ключ —
  F8 → Озвучка или файл `config/viewerparrots-openrouter-token.txt`.
- GameTests приведены к текущему поведению: 23 из 23 проходят.

Старые `viewerparrots-settings.json` читаются без изменений: новые поля
получают значения по умолчанию.

## Установка одним файлом (для стримера без опыта с модами)

Скачайте **`viewerparrots-1.2.0-installer.zip`**, распакуйте и запустите
«Установить Viewer Parrots.cmd». Установщик ставит portable Prism Launcher
в `%LOCALAPPDATA%\ViewerParrots`, создаёт инстанс Minecraft 1.21.1 + Fabric,
кладёт Fabric API и мод, записывает Twitch-канал и делает ярлык на рабочем столе.
Остаётся войти в Microsoft-аккаунт с купленным Minecraft Java Edition.
Подробности внутри архива: `ИНСТРУКЦИЯ.txt`. Повторный запуск обновляет мод,
не трогая миры и аккаунт.

## Установка вручную

Пошаговая инструкция: [quickstart-ru.md](https://github.com/BigZet/minecraft-parrot/blob/main/docs/quickstart-ru.md).

Нужны **Minecraft Java 1.21.1**, **Java 21**, **Fabric Loader 0.19.5** и
**Fabric API 0.116.17+1.21.1**. Положите `viewerparrots-1.2.0.jar` и Fabric API
в папку `mods` своего экземпляра Minecraft.

- `viewerparrots-1.2.0.jar` — готовый мод.
- `viewerparrots-1.2.0-streamer.zip` — тот же мод в папке `mods`, инструкция
  `QUICKSTART-RU.md` и сведения о лицензиях. Fabric API скачивается отдельно.
