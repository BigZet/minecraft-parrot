# Viewer Parrots 1.0.0

Фановый мод для одиночной игры стримера: зрители Twitch-чата создают своих
попугаев и управляют ими. Текущую версию стример проверил вместе с другом
на настоящем стриме.

## Установка с нуля

Пошаговая инструкция: [quickstart-ru.md](https://github.com/BigZet/minecraft-parrot/blob/main/docs/quickstart-ru.md).

Нужны **Minecraft Java 1.21.1**, **Java 21**, **Fabric Loader 0.19.5** и
**Fabric API 0.116.17+1.21.1**. Положите `viewerparrots-1.0.0.jar` и Fabric API
в папку `mods` своего экземпляра Minecraft.

- `viewerparrots-1.0.0.jar` — готовый мод.
- `viewerparrots-1.0.0-streamer.zip` — тот же мод в папке `mods`, инструкция
  `QUICKSTART-RU.md` и сведения о лицензиях. Fabric API скачивается отдельно.

Для чтения публичного Twitch-чата достаточно указать название канала.
Речь через OpenRouter настраивается отдельно и расходует его баланс;
остальные команды работают без OpenRouter.

## Команды зрителей

| Команда | Действие |
| --- | --- |
| `!parrot` | Создать своего попугая |
| `!come` | Позвать его к стримеру |
| `!follow` | Следовать за стримером |
| `!sit` | Сидеть на месте |
| `!free` | Свободно перемещаться и отдыхать |
| `!freefollow` | Свободно перемещаться рядом со стримером |
| `!view` / `!deview` | Начать / перестать смотреть на стримера |
| `!arm` / `!dearm` | Сесть на плечо / уйти с плеча |
| `!dance` | Потанцевать |
| `!spin` | Быстро покрутиться |
| `!scream` | Воспроизвести случайный из пяти настоящих криков попугаев |
| `!say Текст` | Произнести текст своим голосом, максимум 30 слов |
| `!love` | Показать сердечки |
| `!hat` / `!dehat` | Надеть или поменять случайную шляпу / снять её |
| `!exp` | Разбить один пузырёк опыта возле птицы, раз в 30 секунд на зрителя |

У каждой птицы свой случайный голос из 12 вариантов. После первых 12 птиц
используются наименее занятые голоса. Если оба плеча заняты, `!arm` освобождает
одно из них: прежняя птица переходит в `!freefollow`.
