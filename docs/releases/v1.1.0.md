# Viewer Parrots 1.1.0

Фановый мод для одиночной игры стримера: зрители Twitch-чата создают своих
попугаев и управляют ими.

## Что нового

- **Панель управления в игре**: клавиша **F8**, кнопка в главном меню и в Esc.
  Twitch и вход через браузер, команды и роли, лимиты, птицы, поведение,
  голоса, рулетка и профили. Настройки хранятся в `config/viewerparrots-settings.json`;
  старые конфиги импортируются автоматически.
- **`!roulette`**: лента предметов над птицей, приз падает на место попугая.
  Одна рулетка на мир, очередь до 16 заявок, задержка 60 секунд на зрителя.
  Веса и списки призов задаются в `config/viewerparrots-roulette.json`.
- **24 голоса** вместо 12.

## Установка

Пошаговая инструкция: [quickstart-ru.md](https://github.com/BigZet/minecraft-parrot/blob/main/docs/quickstart-ru.md).

Нужны **Minecraft Java 1.21.1**, **Java 21**, **Fabric Loader 0.19.5** и
**Fabric API 0.116.17+1.21.1**. Положите `viewerparrots-1.1.0.jar` и Fabric API
в папку `mods` своего экземпляра Minecraft.

- `viewerparrots-1.1.0.jar` — готовый мод.
- `viewerparrots-1.1.0-streamer.zip` — тот же мод в папке `mods`, инструкция
  `QUICKSTART-RU.md` и сведения о лицензиях. Fabric API скачивается отдельно.

Mob Talk (разговор с мобами голосом) теперь отдельный мод в собственном
репозитории [BigZet/mob-talk](https://github.com/BigZet/mob-talk) и для Viewer Parrots не нужен.
