# Viewer Parrots — установка с нуля

Эта инструкция подходит для нового компьютера. Мод устанавливает только стример:
зрителям достаточно Twitch-чата. Нужна Minecraft **Java Edition 1.21.1**.

Быстрее всего — `viewerparrots-1.1.0-installer.zip` из релиза: он сам ставит
Prism Launcher, Fabric и мод (см. `ИНСТРУКЦИЯ.txt` внутри архива). Ниже — ручной путь.

## 1. Подготовьте Minecraft

Рекомендуемый вариант — [Prism Launcher](https://prismlauncher.org/download/).
В другом лаунчере принцип тот же: отдельный инстанс Minecraft 1.21.1 с Fabric.

1. Установите Prism и добавьте свой Minecraft-аккаунт.
2. Создайте новый инстанс с Minecraft **1.21.1**.
3. В редакторе инстанса, в разделе версий, установите **Fabric Loader 0.19.5**.
4. В настройках Java выберите **Java 21**. Если её нет, установите или загрузите
   Java 21 средствами лаунчера и выберите её для этого инстанса.
5. Скачайте [Fabric API](https://modrinth.com/mod/fabric-api)
   **0.116.17+1.21.1**. Выберите файл для Minecraft 1.21.1.

## 2. Установите готовый мод

Откройте [последний релиз Viewer Parrots](https://github.com/BigZet/minecraft-parrot/releases/latest)
и скачайте из **Assets** файл **`viewerparrots-1.1.0.jar`**.
Архивы `Source code` для обычной установки не нужны.

Можно скачать готовый ZIP-пакет из того же релиза: внутри находится JAR
в папке `mods/` и инструкция `QUICKSTART-RU.md`. Скопируйте JAR в свой инстанс;
Fabric API нужно добавить отдельно.

В Prism откройте папку Minecraft выбранного инстанса через его контекстное меню.
Внутри неё должны находиться папки `mods`, `config` и `saves`.
Поместите в `mods` два JAR-файла:

```text
mods/
  viewerparrots-1.1.0.jar
  fabric-api-0.116.17+1.21.1.jar
```

JAR-файлы распаковывать не нужно. Если обновляете мод, уберите предыдущую
версию Viewer Parrots из `mods`, чтобы остался один JAR мода.
Закройте мир и сохраните его копию перед обновлением.

Все дальнейшие пути `config/...` относятся к **этой папке Minecraft**,
а не к папке, в которую вы скачали мод или установили лаунчер.

## 3. Настройте мод в игре

Нажмите **F8** или кнопку **Viewer Parrots** в главном меню / меню Esc.
Клавиша меняется в стандартных настройках управления Minecraft.
Дополнительный мод для меню не нужен.

1. Откройте одиночный мир. Читы включать не требуется.
2. В панели, на главной странице, нажмите **«Назначить себя стримером»**.
3. В разделе **Twitch** укажите канал, например `numnerd`, без ссылки и `@`.
4. Для публичного чата включите гостевое чтение, примените настройки и подключитесь.
5. Дождитесь `CONNECTED`, закройте панель и напишите в Twitch `!parrot`.

Мир останавливается при открытой панели. Подключение Twitch остаётся живым,
но новые команды зрителей **пропускаются**, а после снятия паузы не накапливаются.
Настройки сохраняются на паузе. Кнопки игровых действий закрывают панель.

Чтобы игра продолжала работать при переходе в браузер, выключите
**F8 → Обзор → Пауза при Alt+Tab**. Переключатель сохраняется сразу в настройках
Minecraft для всего инстанса, независимо от профиля мода. Esc и F8 всё равно ставят мир на паузу.

## 4. Вход в Twitch с автоматическим обновлением доступа

Гостевому чтению авторизация не нужна. Для входа по аккаунту:

1. В разделе **Twitch** укажите Client ID **Public**-приложения Twitch.
   Client Secret не нужен. Если старый токен ещё действителен, мод может определить Client ID сам.
2. Укажите логин аккаунта, отключите гостевое чтение и примените настройки.
3. Нажмите **«Войти»**, откройте показанную страницу Twitch и подтвердите код.
4. После успешного входа подключите чат; при желании включите автоподключение.

Мод сохраняет access token и refresh token локально, проверяет сессию и продлевает её.
При отзыве доступа появится просьба войти снова. Временная ошибка сети не удаляет доступ.
Старый `viewerparrots-twitch-token.txt` поддерживается для совместимости, но для
получения refresh token нужно один раз войти новым способом.

## 5. Проверьте команды

Напишите в чате Twitch:

```text
!parrot
!come
!view
!hat
!roulette
```

Между командами делайте короткую паузу. Повтор `!parrot` не создаёт дубль;
каждый зритель управляет своей птицей. [Все 19 команд](../README.md#команды-twitch-чата).
Для проверки без чата откройте **Попугаи → Создать тестовую птицу**.
В карточке птицы можно выполнить действие и отдельно сбросить её кулдауны.

В рулетке всегда выпадает предмет: по умолчанию лента крутится **4 секунды**,
результат виден **2 секунды**, повторный запуск доступен через **60 секунд**.
Приз падает у попугая, текстовых подписей над лентой нет.
Длительность, задержки, веса, цвета и предметы меняются в разделе **Рулетка**.

## 6. При желании включите речь

В разделе **Озвучка и голоса** вставьте ключ OpenRouter в скрытое поле
и нажмите **«Сохранить ключ»**. Затем включите озвучку и примените настройки.
Нужны платные кредиты OpenRouter. По умолчанию используется
`elevenlabs/eleven-v4-turbo`, 24 голоса и первые 30 слов реплики.

`!say Привет, стример!` воспроизводит реплику голосом птицы зрителя;
`!say [шёпот] Привет` — с интонацией (список стилей в F8 → Озвучка).
Голос закрепляется за птицей; после исчерпания списка выбираются наименее занятые голоса.
Исключение голоса из случайного выбора сохраняет старые назначения.
Прослушивание в библиотеке — отдельный **платный** запрос, который учитывается
в часовых лимитах вместе с обычными репликами. 0 отключает соответствующий лимит.
Расход за последние 60 минут сохраняется между мирами и перезапусками.

Для VPN нужен домен **`openrouter.ai`**: запросы идут на
`https://openrouter.ai/api/v1/audio/speech`.

## 7. Настройки, профили и файлы

Все настройки находятся в `config/viewerparrots-settings.json`.
При первом запуске старые `viewerparrots.json`, `viewerparrots-twitch.json`
и `viewerparrots-roulette.json` импортируются в профиль «Текущие настройки»;
после этого изменяйте настройки через панель или новый файл.
Старые файлы сохраняются, но больше не управляют настройками.
`/vp reload` перечитывает тот же единый файл.

**Профили и прочее** позволяет создавать, копировать, переименовывать,
переключать, экспортировать и импортировать профили. Файлы обмена находятся в
`config/viewerparrots-profiles/`; в экспорт не входят Twitch-аккаунт и секреты.
Смена профиля сохраняет птиц, голоса, действующие кулдауны и расход озвучки.

Сохранение атомарное, предыдущая версия остаётся в `.bak`.
Повреждённый файл не заменяется молча. Настройки с пометкой о перезаходе
сохраняются сразу и применяются после повторного открытия мира.
На Windows токены и новый ключ OpenRouter хранятся отдельно под защитой DPAPI.
Не публикуйте локальные файлы токенов и резервные копии личных настроек.
