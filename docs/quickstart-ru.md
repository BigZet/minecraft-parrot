# Viewer Parrots — установка с нуля

Эта инструкция подходит для нового компьютера. Мод устанавливает только стример:
зрителям достаточно Twitch-чата. Нужна Minecraft **Java Edition 1.21.1**.

## 1. Подготовьте Minecraft

Рекомендуемый вариант — [Prism Launcher](https://prismlauncher.org/download/).
В другом лаунчере принцип тот же: отдельный инстанс Minecraft 1.21.1 с Fabric.

1. Установите Prism и добавьте свой Minecraft-аккаунт.
2. Создайте новый инстанс с Minecraft **1.21.1**.
3. В редакторе инстанса, в разделе версий, установите **Fabric Loader 0.19.5**.
4. В настройках Java выберите **Java 21**. Если её нет, установите или загрузите
   Java 21 средствами лаунчера и выберите её для этого инстанса.
5. Скачайте [Fabric API](https://modrinth.com/mod/fabric-api)
   **0.116.17+1.21.1**. Выберите файл для Minecraft 1.21.1.

## 2. Установите готовый мод

Откройте [последний релиз Viewer Parrots](https://github.com/BigZet/minecraft-parrot/releases/latest)
и скачайте из **Assets** файл **`viewerparrots-1.0.0.jar`**.
Архивы `Source code` для обычной установки не нужны.

Можно скачать готовый ZIP-пакет из того же релиза: внутри находится JAR
в папке `mods/` и инструкция `QUICKSTART-RU.md`. Скопируйте JAR в свой инстанс;
Fabric API нужно добавить отдельно.

В Prism откройте папку Minecraft выбранного инстанса через его контекстное меню.
Внутри неё должны находиться папки `mods`, `config` и `saves`.
Поместите в `mods` два JAR-файла:

```text
mods/
  viewerparrots-1.0.0.jar
  fabric-api-0.116.17+1.21.1.jar
```

JAR-файлы распаковывать не нужно. Если обновляете мод, уберите предыдущую
версию Viewer Parrots из `mods`, чтобы остался один JAR мода.
Закройте мир и сохраните его копию перед обновлением.

Все дальнейшие пути `config/...` относятся к **этой папке Minecraft**,
а не к папке, в которую вы скачали мод или установили лаунчер.

## 3. Откройте мир и назначьте стримера

Запустите инстанс и создайте одиночный мир с разрешёнными командами.
Для существующего мира без команд можно временно включить их через
«Открыть для сети» → разрешить команды; это не требует подключения других игроков.

В игровом чате укажите свой настоящий Minecraft-ник:

```text
/vp setstreamer <ваш_Minecraft_ник>
```

Например, для Minecraft-игрока `StreamerName`:

```text
/vp setstreamer StreamerName
```

Ник Minecraft и логин Twitch могут отличаться. `setstreamer` сохраняется
в этом мире и определяет, к кому птицы прилетают, на кого смотрят и на чьи плечи садятся.

## 4. Подключите Twitch без токена

После первого открытия мира в `config` появляется `viewerparrots-twitch.json`.
Откройте его обычным текстовым редактором и сохраните:

```json
{
  "autoConnect": true,
  "channel": "your_login",
  "login": ""
}
```

Замените `your_login` логином своего канала. Для адреса
`https://www.twitch.tv/your_login` значение `channel` — `your_login`.
Оставьте `login` пустым. Файл `config/viewerparrots-twitch-token.txt`
создавать не нужно; если там уже записан старый токен, очистите его содержимое.

Это гостевое чтение публичного чата. Twitch-приложение, телефон и 2FA не нужны.
Стримеру не обязательно вести трансляцию, чтобы проверить публичный чат канала.

Вернитесь в игру:

```text
/vp twitch connect
/vp twitch status
```

Дождитесь **`CONNECTED`**. Команда `connect` перечитывает настройки;
перезапускать Minecraft после правки Twitch-файла не нужно.
`autoConnect: true` подключает чат при последующих открытиях мира.

## 5. Проверьте своего первого попугая

Напишите в Twitch-чат настроенного канала:

```text
!parrot
!come
!view
!hat
```

Между командами делайте паузу в пару секунд. Птица появится с Twitch-именем
отправителя. Повтор `!parrot` не создаёт вторую птицу.
Все команды действуют на птицу того зрителя, который их написал.

Для проверки плеч отправьте `!arm` и переключитесь в вид от третьего лица
через **F5**. `!dearm` выпускает птицу гулять рядом; `!free` включает обычные
полёты и посадки, `!freefollow` — такое же поведение в окружении стримера.
[Все 18 команд](../README.md#команды-twitch-чата).

**Мир должен быть снят с паузы.** Когда одиночная игра остановлена меню Esc,
сетевые сообщения могут приходить, но игровые команды ждут продолжения игры.
Из мира не нужно выходить: закройте меню и дайте игре несколько секунд.

Для остановки подключения используйте `/vp twitch disconnect`.
Это не удаляет попугаев.

## 6. При желании включите речь

Остальные команды уже готовы к использованию. Для `!say` нужен личный
API-ключ OpenRouter и платные кредиты на аккаунте.

1. Создайте текстовый файл `config/viewerparrots-openrouter-token.txt`.
2. Вставьте в него **только ключ одной строкой**, без кавычек, и сохраните.
   В Windows проверьте, что файл не получил второе расширение `.txt`.
3. Закройте одиночный мир и откройте его снова: ключ читается при запуске мира.
4. Отправьте в Twitch-чат `!say Привет, стример!`.

Используется модель `elevenlabs/eleven-v4-turbo`.
Каждая птица получает постоянный голос из 12 встроенных; после первых 12
повторы распределяются среди наименее занятых голосов.
Текст длиннее 30 слов обрезается. Речь слышна из позиции попугая.

Если используете VPN, доступ к `openrouter.ai` по TCP 443 нужен именно
процессу Minecraft **`javaw.exe` / Java**, а не только браузеру.
[Подробная настройка, другие способы хранения ключа и ошибки](twitch-setup-ru.md#речь-попугаев).

## Если что-то не работает

| Симптом | Что сделать |
|---|---|
| Minecraft не запускается | Проверьте Minecraft 1.21.1, Java 21, Fabric Loader и Fabric API для 1.21.1; уберите дубли JAR |
| `/vp` недоступна | Проверьте установленный мод и разрешение команд в мире |
| `TARGET_NOT_CONFIGURED` | Выполните `/vp setstreamer <ваш_Minecraft_ник>` |
| `AUTH_FAILED` | Для гостевого входа очистите файл Twitch-токена, оставьте `login` пустым и повторите `/vp twitch connect` |
| `CONNECTED`, но птица не появилась | Снимите паузу, проверьте канал и отправьте `!parrot` без дополнительных аргументов |
| `COMMAND_ON_COOLDOWN` | Подождите и повторите команду; задержка считается отдельно для каждого зрителя |
| `SPEECH_NOT_CONFIGURED` | Проверьте имя и содержимое файла OpenRouter-ключа, затем заново откройте мир |
| `SPEECH_FAILED` | Проверьте кредиты OpenRouter и доступ Java к `openrouter.ai` через VPN |

[Подключение Twitch и подробности речи](twitch-setup-ru.md).
Основной конфиг мода: `config/viewerparrots.json`; после изменений — `/vp reload`.
Чтобы сохранить резервную копию, закройте мир и скопируйте всю его папку из `saves`.
