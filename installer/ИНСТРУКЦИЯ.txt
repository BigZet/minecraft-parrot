VIEWER PARROTS — УСТАНОВКА ДЛЯ СТРИМЕРА
========================================

Что это: мод для Minecraft 1.21.1, в котором зрители вашего Twitch-чата
создают своих попугаев командой !parrot и управляют ими.

Что нужно заранее:
  * Windows 10/11 (64-бит) и интернет.
  * Minecraft Java Edition, купленный на вашем Microsoft-аккаунте.
    Bedrock-версия (из Microsoft Store) не подходит.
Больше ничего ставить не нужно: лаунчер, Java и Fabric установятся сами.


УСТАНОВКА (5 минут)
-------------------
1. Распакуйте этот архив целиком в любую папку (например, на рабочий стол).
   Запуск прямо из архива не сработает.

2. Запустите «Установить Viewer Parrots.cmd».
   Если Windows покажет предупреждение «Система защитила ваш компьютер» —
   нажмите «Подробнее» → «Выполнить в любом случае». Это обычное
   предупреждение для неподписанных скриптов.

3. В чёрном окне введите имя своего Twitch-канала (то, что после twitch.tv/)
   и нажмите Enter. Можно оставить пустым и указать позже в игре.

4. Дождитесь надписи «Установка завершена». Откроется Prism Launcher.


ПЕРВЫЙ ЗАПУСК
-------------
1. В окне Prism Launcher нажмите «Добавить Microsoft» (Add Microsoft)
   и войдите в аккаунт, на котором куплен Minecraft. Prism откроет страницу
   Microsoft в браузере — это официальный вход, пароль в лаунчер не вводится.

2. Запустите инстанс «Viewer Parrots» двойным щелчком (или ярлык
   «Viewer Parrots» на рабочем столе). Первый запуск занимает несколько минут:
   скачиваются Java 21 и Minecraft. Дальше запуск обычный.

3. В Minecraft создайте одиночный мир (читы не нужны).

4. Нажмите F8. Откроется панель мода. Нажмите «Назначить себя стримером».

5. Если канал не вводили при установке: F8 → Twitch → укажите канал,
   включите гостевое чтение, нажмите «Применить» и «Подключиться».
   Статус должен стать CONNECTED.

6. Напишите в своём Twitch-чате !parrot — рядом появится попугай.


КОМАНДЫ ЗРИТЕЛЕЙ
----------------
!parrot   — создать своего попугая        !come     — позвать к стримеру
!follow   — следовать за стримером        !sit      — сидеть на месте
!arm      — сесть на плечо                !dearm    — слезть с плеча
!dance    — танцевать                     !spin     — покрутиться
!scream   — крикнуть                      !love     — сердечки
!hat      — случайная шляпа               !dehat    — снять шляпу
!exp      — пузырёк опыта                 !roulette — рулетка с призом
!say текст — произнести фразу (нужен ключ OpenRouter, см. ниже)
!say [шёпот] текст — то же с интонацией: шёпот, зло, грусть, радость,
                     страх, усталость, крик, сарказм
Все команды и задержки настраиваются в F8 → «Команды».


НЕОБЯЗАТЕЛЬНО: ГОЛОС ПОПУГАЕВ (!say)
------------------------------------
Озвучка идёт через OpenRouter и расходует его баланс. Без ключа все
остальные команды работают. Если хотите:
  1. Зарегистрируйтесь на openrouter.ai и создайте API-ключ.
  2. F8 → «Голоса» → вставьте ключ. Он хранится только на вашем компьютере.


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
* «Не удалось скачать» — проверьте интернет; если GitHub не открывается,
  включите VPN и запустите установку снова. Повторный запуск безопасен.
* Первый запуск инстанса висит на «Please wait…» дольше 10–15 минут —
  Prism качает Java и файлы Minecraft (~400 МБ) с серверов Mojang. Через
  медленный VPN это может занять часы: попробуйте выключить VPN (или,
  наоборот, включить, если без него серверы Mojang недоступны) и запустить
  инстанс снова — скачанное сохраняется, загрузка продолжится.
* Prism не запускается — перезагрузите компьютер (мог установиться
  Visual C++ Runtime) и запустите ярлык снова.
* Minecraft вылетает — пришлите файл
  %LOCALAPPDATA%\ViewerParrots\PrismLauncher\instances\ViewerParrots\minecraft\logs\latest.log
* Журнал установки: %LOCALAPPDATA%\ViewerParrots\install.log


ГДЕ ЧТО ЛЕЖИТ
-------------
Всё в одной папке: %LOCALAPPDATA%\ViewerParrots
  PrismLauncher\                                   — лаунчер
  PrismLauncher\instances\ViewerParrots\minecraft\ — моды, настройки, миры
Удалить полностью: удалите эту папку и ярлык с рабочего стола.
Ваш обычный Minecraft и другие лаунчеры установщик не трогает.

Обновление до новой версии: распакуйте новый архив и снова запустите
«Установить Viewer Parrots.cmd» — миры, аккаунт и настройки сохранятся.
