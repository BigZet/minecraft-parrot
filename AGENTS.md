# Рабочие правила Viewer Parrots

Пользователь 14 октября 2026 года явно упростил проект и проверки.

- Это фановый мод для одиночной игры стримера. Зрители Twitch-чата создают
  своих попугаев и управляют ими. Актуальное ТЗ: viewer_parrots_technical_spec.md.
- Twitch-интеграция входит в основной сценарий. Dedicated server, multiplayer,
  online-mode Minecraft и промышленная готовность не являются требованиями.
- Переиспользуйте готовые игровые сервисы. Не переписывайте рабочие слои хранения
  и не добавляйте инфраструктуру без пользы для чат-команд.
- По умолчанию одна сборка через scripts/verify.ps1 (assemble) и короткая проверка
  затронутого сценария. Для документации сборка и игровые прогоны не нужны.
- Запускайте относящиеся к ошибке тесты. Полный набор через verify.ps1 -Extended,
  benchmark, crash matrix и серверные стенды — только при конкретной необходимости
  или явном запросе пользователя.
- После успешной проверки не повторяйте её без изменения или новой ошибки.
  Не запускайте циклы аудитов и сверку всего старого ТЗ ради небольшого изменения.
- Сохраняйте минимум: зритель управляет только своей птицей, Twitch-токен не
  попадает в git/логи/JAR, чат не блокирует игровой поток, очередь ограничена,
  повтор создания не даёт дубль.
- Старый план и отчёты от 13 октября — история, а не действующие блокеры.
- Честно различайте реализованный Twitch-адаптер и проверку настоящего чата.
  Не утверждайте, что настоящий чат проверен, без фактического запуска.
